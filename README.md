# Power Fitness Zone – Website

Premium static website for Power Fitness Zone Gym & Fitness Studio, North Nazimabad, Karachi.

## How to run
1. Place your images in `assets/images/` (map hero.jpg = exterior, gym-1.jpg & gym-2.jpg = interiors).
2. Open `index.html` in a browser or serve with any static server.

## Features
- Sticky glass navbar + mobile menu
- Full-screen hero with rating + open time
- Animated counters, scroll reveals
- Programs, trainers, masonry gallery + lightbox
- Membership cards (WhatsApp CTAs)
- Reviews carousel (auto-play)
- Google Maps embed + directions
- Fully responsive website
