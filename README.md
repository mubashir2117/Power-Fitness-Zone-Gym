# Power Fitness Zone Gym & Fitness Studio

This project is the official website for Power Fitness Zone Gym & Fitness Studio, located in North Nazimabad, Karachi. It's a modern, responsive single-page website designed to showcase the gym's facilities, programs, trainers, and membership options.

## Features

*   **Home Section:** Welcoming hero section with a call to action.
*   **About Us:** Details about the gym's mission, environment, and commitment.
*   **Why Choose Us:** Highlights key benefits like expert trainers, modern equipment, and a positive environment.
*   **Fitness Programs:** Overview of various programs offered, including Weight Training, Weight Loss, Muscle Building, Personal Training, Strength & Conditioning, and General Fitness.
*   **Expert Trainers:** Introduction to the professional trainers.
*   **Gallery:** Visual showcase of the gym's interior and equipment.
*   **Membership:** Information on different membership plans (Basic, Pro, Premium).
*   **Reviews:** Testimonials from satisfied members.
*   **Location & Contact:** Address, opening hours, contact number, and a Google Maps embed.
*   **Social Media Integration:** Links to Instagram, Facebook, and WhatsApp.
*   **Responsive Design:** Optimized for various devices.

## Technologies Used

*   HTML5
*   CSS3 (with custom styling in `css/style.css`)
*   JavaScript (for interactive elements, `js/script.js`)
*   Font Awesome (for icons)
*   Google Fonts (Bebas Neue, Inter, Oswald)

## Getting Started

To view the website locally, simply open the `index.html` file in your web browser.
